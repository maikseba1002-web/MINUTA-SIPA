ℹ️ ¿Cómo obtengo el token y el chat_id? (clic para ver pasos)

La copia incluye los pasos de creación y el bloque listo para pegar en @BotFather después de enviar /setcommands.

1) Crear el bot:
• Abrí Telegram → buscá @BotFather
• Mandale /newbot, elegí nombre y username (ej: sipa_cuello_bot)
• Te devuelve un token tipo 123456:ABCdefGHI-... → ese va en el campo "Token".

2) Comandos para pegar en @BotFather:
• Enviá /setcommands, seleccioná tu bot y pegá este bloque completo:

ausentes - ❌ Ausentes hoy

3) Obtener el chat_id del grupo:
• Creá un grupo privado en Telegram con la gente de Plana Mayor.
• Agregá el bot al grupo (Add member → @sipa_cuello_bot).
• Importante: en BotFather, mandá /setprivacy → DISABLE → para que el bot pueda leer del grupo.
• Mandá cualquier mensaje al grupo (ej: /start).
• Abrí en el navegador: https://api.telegram.org/bot<TU_TOKEN>/getUpdates
• Buscá "chat":{"id": -100xxxxxxxxxx,... → ese número (incluido el signo negativo) va en "Chat ID".
Se almacena cifrado en config_sistema. Dejá vacío para conservar el actual.
Para grupos arranca con -100. Para chat directo, número positivo.

🚨 ADVERTENCIA

Las siguientes acciones modifican la base de datos de forma irreversible. Antes de operar, descargue un respaldo.

💾 Respaldo (Backup) de la Base

Descarga un JSON con el contenido completo de las 7 tablas (cronogramas, padrones, firmas, minutas, justificaciones, configuración).

♻️ Restaurar desde Backup

Cargue un archivo .json de respaldo. ⚠️ Esta operación BORRA las tablas actuales antes de restaurar.

📦 Archivar Ciclo Lectivo Anterior

Mueve minutas y firmas de un año cerrado a las tablas minutas_archivo y firmas_archivo (solo lectura), liberando la base operativa.

♻️ Purga del Cronograma Maestro

Elimina solo la tabla cronograma_maestro. Útil cuando un Word vino mal y hay que recargar el horario sin tocar firmas, padrón ni minutas.

🗑️ Vaciar y Resetear Tablas (Fin de Ciclo)

Trunca todas las tablas operativas. Tipee la frase de confirmación exacta para liberar el botón.
